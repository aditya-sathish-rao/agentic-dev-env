agentic-dev-env, reviewed against its own principles

A macOS environment-as-code repo: nix-darwin, home-manager and Homebrew, plus the first-mate crew that runs on it. Reviewed for architecture (seams, depth, boundaries) and for code (the check module, the wrappers, the flake), then refined in place.

The one-sentence answer

1. The boundary that leaked

home.nix links repo directories into $HOME with mkOutOfStoreSymlink. For wezterm and nvim only a human writes there. For herdr the program itself writes, so a whole-directory link made the git working tree herdr's state directory.

2. What the architecture already gets right

Three seams carry this repo. They are the benchmark the findings below are measured against, and none of them needed changing.

identity.nix, one seam for who this is

Three values in (username, homeDirectory, host), one place that reads the environment, one actionable throw when it cannot. Four consumers: flake.nix, configuration.nix, home.nix, rebuild.sh.

Nothing hardcodes the user, so the same clone configures whoever runs it.

tools.nix, one list two adapters

Nine formatters and linters, consumed twice: user packages in home.nix and the CI dev shell in flake.nix. Two real adapters justify the seam, and CI cannot drift from the machine.

Adding a tool is one line in one file.

check, one gate three callers

The pre-commit hook, the dev shell and CI all run the same module. The gate already enforces one non-obvious invariant: every principle-* directory must appear in the index skill.

That check is the pattern the fixes below copy.

Ordered by what breaks if it stays. "Verified" means the failure was reproduced or the fix was proven against the real artifact, not reasoned about.

4. The changes

Five files. Each change removes a way for the system to be silently wrong, and none adds a layer.

4.1 The gate classifies by shebang, not only by extension

.githooks/check. The extension list stays first; anything unclassified gets its first line read. This is the root-cause fix for finding 2, not a special case for one filename.

4.2 herdr links a file, not a directory

home.nix. Same shape as the ~/.pi/agent entries right below it: link the config, let the program own its state directory.

4.3 The link table is validated at evaluation time

home.nix. The table is the only hand-written seam between repo and $HOME, and it was the only one with no guard at the boundary. A new let-binding collects targets that do not exist, and the module body opens with assert lib.assertMsg (missingSources == [ ]). Because check --all evaluates the flake, CI enforces it too.

4.4 The wrapper decides on the first argument only

home/.local/bin/pi. A probe is the first token. The re-exec also names the wrapper by absolute path, so the vault round trip lands back on this file exactly once.

Plus two one-liners: typeset -U path before the $HOME/.local/bin prepend in the generated .zshrc, and permissions: contents: read + a concurrency group in .github/workflows/checks.yml.

6. Deliberately not changed

The rest of the check module

The seven file types are still encoded three times: classify, format, lint. A table would collapse them, but macOS ships bash 3.2, which has no associative arrays, so the table would need parallel arrays to save nothing. Finding 2 was the real cost of the duplication, and fixing classification removed it.

tailscale.nix stays a module

One line, one interface, so by the deletion test it is a pass-through. It is also the named place daemon flags will go. It was raised in the 2026-11-17 review and kept, which is a decision; recorded here so it stops reappearing as a finding.

Hack Nerd Font is installed twice

home.packages (with home.fonts.fontconfig) and fonts.packages both carry it. One is probably redundant, but proving which one WezTerm and VS Code actually resolve needs a GUI launch this review cannot perform, so it stays.

no-comments is untracked

home/.agents/skills/no-comments/ is on disk but not in git. A rebuild will link it; a fresh clone will not have it. Commit it or delete it, but decide on purpose.

One eval warning is upstream noise, not this repo: Using 'builtins.derivation' to create a derivation named 'options.json'. It appears before and after these changes, from the nix-darwin option docs.
